# Among the Pines
*A small first-person survival game (Cabin Survival)*
Developed in Unity during Summer 2026.

The player must gather resources, manage hunger, maintain their campfire, and survive through multiple day-night cycles while exploring a small forest surrounding a cabin.

## Features

### Core Systems
- First-person movement
- Interactable environment
- Small explorable environment
- Axe and tree chopping system
- Wood gathering
- Hunger system
- Food collection and consumption
- Campfire fuel management
- Day and night cycle
- Win and lose conditions

## Gameplay Loop
1. Explore the environment.
2. Gather resources such as wood and food.
3. Return to the cabin before night.
4. Maintain the campfire and manage survival needs.
5. Survive for a set number of days to win.

## What I learned

Switching from 2D to 3D came with a real learning curve — terrain tools, camera rigs, and world-space interactions all work differently. I got comfortable with it within a week and started building out the environment.

The first version had no clear gameplay loop — just assets placed on the ground with no structure or win condition. It looked like a game but didn't play like one. I restarted from scratch, deliberately reduced the terrain size to constrain the scope, and focused on getting one complete loop working first: gather → survive the night → win or lose. That constraint made everything else easier to build around.
